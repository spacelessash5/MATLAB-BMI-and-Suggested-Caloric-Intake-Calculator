--Description--
This MATLAB Program calculates users' Body Mass Index (BMI) and daily caloric intake based on inputs such as height, weight, activity level, etc.
This program may work with one or multiple subjects; you may enter multiple subjects' information into the program at once.
Outputs include subjects' data from user inputs, users' BMI values, their BMI categories (underweight, overweight, etc.), and their suggested daily caloric intake, as well as summary statistics including mean, minimum, and maximum BMI among all subjects and number of subjects in each BMI category.

--How to use--
You will need to have MATLAB installed to run the program (R2025b or a similarly recent version). 
Install all .m files. The main script is housed on finalproject.m, with user-defined functions included in all other .m files.
Open your files in MATLAB and run finalproject.m.
Enter information about subjects, including names, number of subjects, weights, heights, ages, genders, and activity levels on a pre-determined scale as prompted by the program.
Once all information is entered, you will receive your outputs, as well as an option to calculate subjects' caloric needs at different weight goals or activity levels if desired.
